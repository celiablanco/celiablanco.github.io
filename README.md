# celiablanco.github.io

Personal website of Dr. Celia Blanco, in English and Spanish, built with
[Astro](https://astro.build) and published at <https://celiablanco.github.io>.

## Requirements

- Node.js 22 (pinned in `.nvmrc`; the deploy workflow reads the same file)
- Python 3 with the packages in `scripts/requirements.txt`, only if you need
  to regenerate the fitness landscape figure

## Commands

```sh
npm ci            # install dependencies from package-lock.json
npm run dev       # local dev server at http://localhost:4321
npm run build     # production build into dist/
npm run preview   # serve the built dist/ locally
```

## Structure

```
src/pages/          English pages (index, research, publications, opportunities, contact)
src/pages/es/       Spanish versions of the same pages
src/layouts/        BaseLayout.astro (head, fonts, header, footer)
src/components/     Header, Footer, Starfield
src/styles/         global.css (colour and spacing tokens, shared styles)
public/img/         images served as-is
scripts/            figure generation
```

Every page exists in both languages. When you change content, update the
English file and its `es/` counterpart together.

## Updating content

**Publications**: edit the `inProgress` and `groups` arrays at the top of
`src/pages/publications.astro` and `src/pages/es/publications.astro`. Each
entry has `authors`, `title`, `venue` (formatted as
`Journal, volume(issue), pages`), a `doi.org` link in `href`, and optional
`extras` for press links. Papers are listed newest first within each year.

**Research areas**: edit the `research` array at the top of
`src/pages/research.astro` and `src/pages/es/research.astro`. Each area has a
figure (`img`), a screen-reader description (`alt`), and HTML `body` text.
Link papers with `https://doi.org/...` URLs.

## Fitness landscape figure

`public/img/research/fitness_landscape_rugged.png` is generated by a script:

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/generate_fitness_landscape.py          # rewrites the website image
python3 scripts/generate_fitness_landscape.py --pair   # smooth + rugged, side by side
```

## Deployment

Pushing to `master` runs `.github/workflows/deploy.yml`, which builds the site
and publishes `dist/` to GitHub Pages. The workflow can also be started by hand
from the repository's Actions tab.

The site loads its fonts (Fraunces and Inter) from Google Fonts; everything
else is served from this repository.
